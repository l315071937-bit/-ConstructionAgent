# 评估数据集约定（01 52.5）

## 查询集结构（datasets/*.json）

{
  "name": "建筑电气方案检索-样本集-001",
  "queries": [
    {
      "query": "低压配电箱安装有什么要求？",
      "relevant_chunk_ids": ["<chunk_id>"],
      "golden_facts": ["配电箱安装工艺流程包含弹线定位"]
    }
  ]
}

## 数据来源计划

1. 检索类：50~100 条真实查询，来自《建筑电气工程施工方案.doc》等语料，
   由人工标注 relevant_chunk_ids（qrels）；
2. 生成类（方案）：golden_facts 由工程师标注关键参数/工艺要点；
3. 方案长文档人工评审量表（02 8.20，V1 方案阶段启用）：
   - 事实错误数（跨章一致性，plan_facts 比对）
   - 规范引用正确率
   - 结构完整度（按模板章节覆盖率）
   - 直接可用率（工程师估计"修改后可用"的比例）
